A-UniFind — Windows desktop app

Run A-UniFind.exe from a folder where you can save files (for example, Documents or Desktop). The app creates its records and staff account database beside the executable. On first launch, register one staff name using letters and spaces only and a password. Staff names and passwords are case-sensitive when signing in. Student browsing needs no account.

A-UniFind.py is the matching Python source code for the DASTAL submission. a_unifind_logo.png is included for running the source directly with Python. The logo is bundled inside the executable.

This folder contains no records or staff credentials. Keep the executable and its data files together once you start using it. The app prevents two copies from editing the same records at once.
